# 작혼 기준 용어

마작 관련 모든 용어는 작혼(雀魂) 기반으로 쓴다. 한국식·중국식 표기를 섞지 않는다.

- 오야 / 코 (친·자 아님)
- 오시 / 오리 (푸시·폴드 아님)
- 리치, 텐파이, 노텐, 쯔모, 론, 방총, 유국, 도라, 우케이레, 샹텐, 스지, 현물

**Why:** 작혼이 기준 경험이다. 용어가 섞이면 화면과 코드가 동시에 어색해진다.

**How to apply:** UI 라벨, 보고서 문구, 대화 설명, 코드 식별자(`isOya`, `payments.oya/ko`)까지 작혼 용어로 맞춘다. 새 용어가 필요하면 작혼에 그 표현이 있는지 먼저 확인한다. [no-explanatory-text-in-ui](no-explanatory-text-in-ui.md), [unify-same-role-element-specs](unify-same-role-element-specs.md)와 함께 적용.
