# 프로젝트 컬러셋

전체 컬러셋은 다음 5색으로 고정한다.

- `#CCD5AE` — 세이지 그린 (가장 진한 녹색조)
- `#E9EDC9` — 연한 라임 크림
- `#FEFAE0` — 아이보리 (가장 밝음)
- `#FAEDCD` — 웜 크림
- `#D4A373` — 탠 (가장 진한 색, 강조/포인트)

**How to apply:** 배경은 `#FEFAE0`/`#FAEDCD`, 면 구분과 보조 영역은 `#E9EDC9`/`#CCD5AE`, 강조·액션·주요 텍스트 대비는 `#D4A373` 축으로 잡는다. 이 5색 밖의 색은 쓰지 않는다(명암 대비가 부족한 텍스트는 이 계열의 어두운 톤을 파생해 사용). 값은 CSS 변수/토큰으로 한 곳에 정의해 공유한다 — [unify-same-role-element-specs](unify-same-role-element-specs.md).
